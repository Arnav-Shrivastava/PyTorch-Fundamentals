# PyTorch Fundamentals: Zero to Confident

A masterclass learning repository and practical implementation of core PyTorch concepts built from first principles through a professional Fashion-MNIST clothing classification project.

## Overview
This repository contains a guided, pedagogical journey through the core abstractions of PyTorch:
- Tensors & Memory Layouts
- Computational Graphs & Autograd
- Object-Oriented Neural Network Modules (`nn.Module`)
- Datasets, Transforms & High-Throughput DataLoaders
- The Canonical 5-Step Training Loop
- Diagnostics & Common Failure Modes (Memory leaks, evaluation mode, zero-grad omissions)
- Production Model Checkpointing & Resumption
- GPU Memory Optimization & Mixed-Precision Training (AMP)
- Modular CLI Training (`train.py`) & Inference Pipelines
